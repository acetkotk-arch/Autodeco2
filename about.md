# Auto Deco

One-click level decorator for the Geometry Dash editor.

Select a few decoration objects you like (gears, glows, particles...), open the editor pause menu and press **Auto Deco**. The mod reads your level, finds block surfaces, corners, hazards and empty background space, and fills them with your palette.

- Styles: Clean, Detailed, Chaotic
- Adjustable density, object cap and seed (same seed = same layout)
- **Undo Deco** removes everything Auto Deco added this editor session
- Only decoration objects are ever placed - never portals, triggers or hazards

Tip: save a copy of your level before using it.
